# Type-scale audit — 2026-10-18 (phase 5)

Typography-only proofcheck of every dev route against its Figma frame after the per-screen sync.
Inputs: `.design-sync/typescale/after/*.png` (28 routes, iPhone 16 Pro Max), `before/*.png` (10 routes),
Figma renders of the newest frame per screen (file `XRUD89H31ESUrvf9fGMtjW`), and a role-by-role read of
each screen's component files against the four `mapping-*.md` plans.

Verdicts: **match** = sizes/weights/hierarchy equal the newest frame and every call site is on the mapped
role · **minor** = metrics right, but casing/copy differs from the frame or a shared DS primitive still
carries the old role · **miss** = a wrong role, a leftover literal/alias, or a new clip/truncation.

**Counts: 22 match · 5 minor · 1 miss (fixed in this audit).**

Role legend used throughout: Figma Display→`display`, Title-large→`titleLarge`, Title-medium→`titleMedium`,
Title-small→`titleSmall`, Body-large→`bodyLarge`, Body→`body`, Body-medium→`bodyMedium`, Label→`label`,
Caption→`caption`, Caption-medium→`captionMedium`, Overline→`overline`; raw SemiBold 13→`labelStrong`,
SemiBold 14→`titleXsmall`, SemiBold 15→`bodyStrong`, SemiBold 16→`headline`, Bold 15→`feedRowTitle`.
